# DiskEye v0.9.8 — 真图标 + 搜索栏响应式 + 非监控盘历史清理（2026-09-16）

## 用户反馈 → 处置（3 条）

| 反馈 | 根因 | 处置 |
|---|---|---|
| "文件夹重灾区第一还是 C:\...\Temp" | C 盘行是**盘符过滤上线前（v0.9.0~0.9.6）的历史数据**，过滤只拦新数据不删旧数据 | ①新增 `PurgeWritesOutsideDrives`，启动时自动清非监控盘历史字节；②当前库已清（write_bytes 全表只剩 D 盘 8868 行），重灾区 top3 变为 D 盘真实目录 |
| "任务栏没图标（托盘有）" | **主窗图标是空白位图** `new Bitmap(32,32).GetHicon()`——任务栏按钮在但显示白块 | 新建 `AppIcon.Eye` 统一图标（眼睛），窗体/托盘共用；TrayIconManager 旧 MakeEyeIcon 删除 |
| "搜索按钮字出不全，全面美化" | 搜索栏硬编码坐标（TextBox Left=220/宽 500、清空按钮 Left=730），窗口拉宽/字体变化后错位裁字 | 搜索栏重排为**响应式**：TextBox Left|Right 锚定自适应伸缩，清空按钮 76px 锚定右侧+Resize 重排 |

## 备注

- 任务栏图标若仍显示旧白块：Windows 图标缓存，重启资源管理器或下次登录刷新。
