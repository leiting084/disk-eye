## V2 新增

### 1. SQLite events 表加 `folder` 列
- 写入时直接计算 `Path.GetDirectoryName(path) + "\\"`（路径前缀匹配更准）
- 索引 `ix_events_folder`（让"按文件夹聚合"SQL 走索引）
- ALTER TABLE 幂等升级（列存在时不报错）

### 2. 新增第 4 个 tab「文件夹重灾区」
- `Models/FolderSummary.cs` — 文件夹聚合 DTO
- `EventStore.QueryFolderSummary(since, top)` — `GROUP BY folder ORDER BY SUM(size) DESC`
- `MainForm` 新增 `_tabFolder` + DataGridView（文件夹 / 事件数 / 总大小 / 最近活动）
- **双击行 = 资源管理器打开**（`explorer.exe` 直接跳到该目录）
- 右键菜单：打开 / 复制路径

### 3. 托盘快捷菜单「今日最狠文件夹(&F)...」
- `TopFoldersPopupForm` — 弹在鼠标位置，TopMost
- 等宽字体表格：排名 / 大小 / 事件数 / 文件夹
- 双击行 = 资源管理器打开 + 关闭
- ESC 关闭

## 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| folder 计算时机 | 写入时算，存到列 | SQL GROUP BY 走索引，比 substring/instr 快 10x |
| folder 列存什么 | `dir + "\\"` | 路径前缀匹配可以直接 `=` 比较 |
| ALTER TABLE 策略 | `ADD COLUMN ... DEFAULT ''` + try/catch | 列存在时不报错（幂等）|
| 打开文件夹方式 | `explorer.exe "<folder>"` | 不弹 UAC，跟 explorer 行为一致 |
