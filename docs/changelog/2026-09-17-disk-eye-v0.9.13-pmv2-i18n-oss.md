# DiskEye v0.9.13 — PerMonitorV2 锐利渲染 + 双语框架 + 开源准备（2026-09-17）

## 1. DPI 问题的正确解（用户指出 DpiUnaware 会糊）

用户认知正确：DpiUnaware 是"100% 渲染再放大 1.5x"——文字变大且糊，不是精致。
正解 = **PerMonitorV2 原生渲染**（每屏锐利）+ **全局字体 8.25pt**（比默认 9pt 小而精致）：

- csproj `<ApplicationHighDpiMode>PerMonitorV2</ApplicationHighDpiMode>`
- Form.Font 8.25pt；表格行高 26→22、表头 30→26、tab 高 32→28；图表字号同步缩小
- AutoScaleMode 改 Dpi（移除错误基准的 Font 模式）
- 状态条/按钮高度自适应（v0.9.11）继续兜底

## 2. 双语框架（中文默认 / English）

- `Forms/L.cs`：静态字典翻译器；字典**内嵌资源**（`Strings.zh.json` / `Strings.en.json`）——
  刻意不用 resx 卫星程序集，保持**绿色单 exe** 交付
- 缺 key 回退链：en → zh → key 本身
- AppConfig.Language 字段（zh 默认）；Program.Main 在窗体构建前 L.Load
- 已接入：8 个 tab 标题、榜单/清理全部列头、4 个 hint、状态条、托盘菜单/tooltip/今日写入、
  清理扫描全流程文案（约 60 key）
- 切换语言：改 config `"Language": "en"` 重启生效（设置界面下拉后续加）
