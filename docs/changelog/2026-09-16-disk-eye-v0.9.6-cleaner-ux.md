# DiskEye v0.9.6 — 垃圾清理 tab + 字节口径纠偏 + 体验包（2026-09-16）

## 用户反馈 → 处置（6+2 条）

| 反馈 | 处置 |
|---|---|
| "DiskEye 排第一，往 C:\...\Temp 写什么？不是绿色么？核实" | **实锤**：etilqs_*（sqlite 反写）临时文件，每天 ~1800 个×7MB≈**12GB**——SQLite 大查询溢出到 %TEMP%。修：`PRAGMA temp_store=MEMORY`（+cache 32MB），垃圾写**归零**。本体绿色性不受影响（config/db/日志仍在 exe 旁），今日榜上 DiskEye 的 12GB 是历史累计，次日归零 |
| "排行榜要能看到往哪倒垃圾" | 凶手指控榜新增"主要写入目录"列（write_bytes 按 pid+folder 聚合 top1） |
| "部分可执行路径空" | 回填：同 pid 已知 exe 路径补空行（每 60 秒后台）；确实拿不到的显示"（未知——进程已退出且未抓到 exe）" |
| "部分还是 unknown" | 再加一路：同路径已知写者回填（events ← write_bytes 同 path 的 pid/名字） |
| "加个能识别能清理的 tab" | 新增**垃圾清理 tab**：白名单扫描（用户 Temp/Chrome/Edge 缓存/缩略图缓存），Temp 只删 24h 前旧文件、被占自动跳过、清完重扫；绝不出白名单（claude-code/node_modules 明确不碰） |
| "美化" | 所有表格 StyleGrid 统一：双缓冲、行高 26、表头/斑马纹/选中色 |
| "今日趋势鼠标一动就闪" | 图表双缓冲 + Pen/Brush/Font 静态缓存（原每帧 new，闪烁+GDI 泄漏） |
| "托盘只有双击，要右键菜单" | 实锤：菜单从 V0.8 构建了但**从未绑定** `_tray.ContextMenuStrip`，补一行激活；tooltip 注明双击/右键 |
