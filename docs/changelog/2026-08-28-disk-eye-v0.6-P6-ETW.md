## P6 实施

### V6.1 P/Invoke Win32 ETW
- 用 P/Invoke 直接调 `EtwEnableTraceEx2` + `OpenTrace` + `ProcessTrace`
- 启用 `Microsoft-Windows-Kernel-File` provider（FileIO 关键字）
- 解析 `EVENT_RECORD` 拿 PID + FileName
- 提供 `Resolve(filepath)` API
- 失败时自动降级到 Process 启发式

### V6.2 P3 性能优化
- #2 ComputeStats 移到 EventStore（架构一致性）
- #3 Error 重建 watcher 异步化（Task.Run）
- #4 MessageOnlyForm 复用单例（GC 压力）
- #5 SurgeLoop 检查间隔可配（响应 SurgeWindowSeconds 变化）

### V6.3 顶栏搜索框
- MainForm 顶部加 TextBox
- 跨所有 tab 过滤（实时搜索）
- 进程名 / 路径 / PID 匹配

### V6.4 自启延迟 30 秒
- Program.cs 解析 `--delay N` 参数
- 注册表项写入 `--minimized --delay 30`
- 避免开机时和系统 IO 抢资源
