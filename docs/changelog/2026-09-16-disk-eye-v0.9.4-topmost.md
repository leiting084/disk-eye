# DiskEye v0.9.4 — 打开窗口强制置顶（2026-09-16）

## 现象

v0.9.3 修完屏外坐标后，用户仍喊"tab 排名看不到"。全屏截图揭示：窗口在屏内正常位置、内容完整，但**Z 序在所有窗口底下**——后台进程的 Activate() 被 Windows 前台锁定策略拒绝，窗口弹出后被其他窗口盖住，用户以为没弹出。

## 修复

RestoreToScreen 三件套补全：
1. 最小化 → 还原（v0.9.3）
2. 屏外 → 搬回主屏（v0.9.3）
3. **Z 序底部 → TopMost 闪烁强制置顶**（v0.9.4 新增：TopMost=true → Activate → TopMost=false → BringToFront）

## 验证

- SHOW 管道触发后全屏截图：窗口在最前层，凶手指控榜完整（DiskEye 14.9GB 第一、rustc 第二、node/chrome/dotnet/link/微信/豆包等几十进程）、跨 tab 搜索栏可见。
- UI 探针 9ms 应答；67 xunit 绿。
- 交付 publish_v94；运行实例已替换（保留当日库）。

## 用户可见性排查链（后续照此诊断）

1. 进程在？→ 2. 窗口可见？→ 3. rect 在屏内？→ 4. **Z 序是否被盖** → 5. 内容是否有数据。
层次不同，症状都是"看不到"。
